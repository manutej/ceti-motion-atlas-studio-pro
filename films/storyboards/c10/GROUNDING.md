## Accuracy cautions for this cluster
- A passing gate means "no catalogued failure", not good teaching ("Beauty is not a gate").
- Deterministic means reproducible, not correct.
- A hash or a stamp shows a file is unchanged since registration, not that it is good, true or authored by anyone. There is no signing.
- There is no learning-outcome evidence for these explainers yet. Never claim a film "teaches better".
- tell-apart's only deductive claim is about function composition; "orbit", "quotient", "invariant" and "certified" are banned.
