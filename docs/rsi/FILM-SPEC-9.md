# The 9-element film spec (owner-supplied, 2026-10-22; source image: film-spec-source.png)

Every explainer / motion-graphics brief carries all nine. Lines marked ⟂ are machine-checkable and become gates.

1. **Film in one line.** The logline and the joke, so every decision can be checked against it.
2. **References.** Source video, song, image library, a GitHub repo of prior work. What to keep, what to push.
3. **Tools & keys.** Skills to load, APIs available (image, video, voice), budget, where docs live. "Spend it economically."
4. **Character bible.** Proportions, palette sampled from a sheet, expressions, an identity lock that survives every style change.
5. **Beat sheet.** Acts with timestamps, a visual payoff every 3 to 5 seconds ⟂, a hook in the first 2 ⟂.
6. **Text on screen.** When lyrics or captions go huge, when they sit like subtitles. Composition leaves room for them ⟂.
7. **Workflow gates.** Plan → rig → stills → animatic → full pass → polish → audio → render. Don't skip gates ⟂.
8. **Critique loop.** Render stills, score them, write the 3 worst problems, fix, repeat until every score is 8+ ⟂.
9. **Deliverables.** Final MP4, loop check, poster frame, contact sheet, clean source with a README ⟂.
