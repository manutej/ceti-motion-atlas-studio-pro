# CONTRACT — lane `vector` (round 3, module `SCENE`: per-beat scene primitives so `show` = drawn)

Film line (BRIEF §1 / EVAL-v9 D4): *the pictures must tell the same story as the words — every beat draws its own `show`, the breather is the emptiest frame, the whale is a character, not the set.* Closes INTEGRATION-PLAN step 6 (G38) and MUT-20.
Module name `SCENE`. Candidate: `work/vector3/cand-<I>.js` exposes `window.SCENE_<I>` + `module.exports`; soup: `window.SCENE`, shipped as `studio-scene.js` (≤ 16 KB) loaded after `studio-two-renderer.js` (untouched: G31 text predicates stay green). IIFE; no-op (`render` returns false, zero ctx ops) when `TWO_LAYER` is absent or `!TWO_LAYER.isAvailable()`. Extra return fields: **forbidden**.

## API
```
SCENE.fromBeat(beat, tokens, seed) → { primitives: [ { kind ∈ card|arrow|bracket|counter|pill|stack|path|mask, id, role ∈ paper|ink|accent|highlight|contrast,
      box{x,y,w,h} (frame fractions), label?: string, from: string (substring of beat.show, case-insensitive), word: int, at?: sec, n?: int (stack), to?: id (arrow|path) } ],
   character: { visible: bool, pose: {x,y,rot,scale,rung}, box{x,y,w,h} }, hotspot: {x, y} (fractions), textBox: {x,y,w,h} }
SCENE.render(ctx2d, scene, t, pass ∈ 'back'|'front', opts{beat, palette, seed, P, sheet, reduced?, captionsCovered?}) → false | TWO_LAYER meta
SCENE.coverage(scene) → { showTermsMatched: string[], unmatched: string[] }      // unmatched.length === 0 is G38 "show = drawn"
SCENE.terms(show) → string[] · SCENE.toDiagram(scene) → { nodes[], edges[] } · SCENE.VERSION
```
`render` draws ONLY through the existing grammar: it builds `b2 = Object.assign({}, beat, { diagram: toDiagram(scene), focus: {x: hotspot.x, y: hotspot.y, r: 0.2}, counter: <the counter primitive or undefined> })` and calls `TWO_LAYER.renderFrame(ctx, t, b2, palette, seed, P, {pass, sheet, reduced, captionsCovered})` — `diagramOf` short-circuits on `beat.diagram` (renderer L218), `focusOf` on `beat.focus` (L186). SCENE never constructs an item, a colour, or a font; `role` is metadata for audit/coverage, the ink is the grammar's (`C.a` fill, `C.c` stroke, `C.h` head).
Kind → grammar (fixed, so candidates differ in *which* primitives, not *how* they draw): `card`/`pill` → node `{id, x, y, label, shape:'pill', word}` (card: label ≤ 3 words, box w ≥ 0.16; pill: ≤ 2 words, w < 0.16) · `stack` → `n ∈ 2..6` pill nodes `id+'_'+i` fanned by `(+0.025·i, −0.02·i)`, label on the last only · `arrow` → edge `{from:id, to, kind:'arrow', word}` · `path` → `arrow` edge through ≥ 2 `dot` nodes (`id+'_d'+i`, label `''`) placed on the segment · `bracket` → edge `{from:id, kind:'bracket', word}` on its own pill · `counter` → `beat.counter {from, to, unit, x, y, word}` (one per scene max) · `mask` → nothing drawn: it IS the hotspot (exactly one per scene, equals `hotspot`). Node `x,y` are the box centre; `y` is set explicitly (the grammar's default 0.8 sits inside the text box). Every `id` = `'b' + beat.index + '_' + slug(label || kind)`.

## Beat fields read, with defaults (both example boards carry every field in the first group; the second group is absent on both and defaults)
Present: `beat.show` (string) · `beat.say` · `beat.index` · `beat.grammar` · `beat.textBox {x,y,w,h}` (0.08/0.76/0.84/0.16; breather 0.3/0.42/0.4/0.12) · `beat.tStartSec/tEndSec/tMidSec` (from `dur` via `buildV9Board`) · `beat.characterPose {x,y,rot,scale,rung,…}` (set by `buildV9Board`) · `beat.plant` (hook) / `beat.returns` (callback|landing) · `beat.cameraMove` · `beat.snap` ('none' after normalisation).
Absent → default: `beat.character` → **absent ⇒ `character.visible = false`** (the legacy `pr.draw` whale/s_retrieve art is drawn by the host only when visible, inside `character.box`; `pose` = `beat.characterPose` or `{x:.5,y:.5,rot:0,scale:1,rung:1}`, `box` = `{x: pose.x−0.12·scale, y: pose.y−0.12·scale, w: 0.24·scale, h: 0.24·scale}`) · `beat.scene` (a host-authored override) → when present and `{primitives:[…]}`, `fromBeat` returns it normalised instead of inferring · `beat.focus`/`beat.diagram`/`beat.counter` → ignored on input (SCENE owns them on `b2`).
Timing source: a primitive lands on the `say` word `word` via the grammar's clock (`sayTiming.at(word)`, renderer L77-87, which already applies `snap`); default `word` = reading order spread `round(i·(n_words−1)/(m−1))` (`m` = primitives, `0` when `m = 1`); `at` overrides in seconds on the storyboard clock and must lie in `[tStartSec, tEndSec)`. No `say` ⇒ all land at `tStartSec + 0.35·dur`. Never NaN: a missing `tEndSec` ⇒ `tStartSec + 1.5`.
Inference order (top to bottom): 1 `beat.scene` override · 2 quoted phrases in `show` (`'two weeks'`) → `pill` with that label · 3 the `plant` / `returns` phrase → `card` with role `highlight` (the callback's card reuses the hook's `box`) · 4 remaining `terms(show)` in `show` order → `card`; two terms joined by `into|between|out of` → `arrow`; `grow|past|more|less` + a number word or `bars` → `counter`; `potholes|detours|pages|cards` + a count word (`two`..`six`, `three`) → `stack` with that `n` (default 3) · 5 `grammar === 'breather'` ⇒ keep the first 2 primitives only, no arrows · 6 `hotspot` = the centre of the primitive whose `word` is largest (the last to land), else `character.box` centre.
`terms(show)`: lower-case; quoted `'…'` phrases kept whole; the rest split on `[^a-z]+`, keep words ≥ 4 letters not in STOP = `the and into from with that this then than them they their there here still hold holds wide open empty space back first frame echoing echo beat appears appear slide slides turns turn reads reading grow grows growing keeps keep past side floats float taps tap opens sprouts flips fans hammers calm pull pulls small each plugs plug reaches reaching shows show smooth straight labeled leans corner ground between`. A term is matched when it is a substring of some primitive's `label` or `from` (lower-cased); `robot|character` is also matched by `character.visible === true`.
Tokens: `tokens.color` roles `paper ink accent highlight contrast` exist; `tokens.type` roles exist (not used: the grammar sets fonts); `tokens.motion.feels` have names and **no easing** (if a feel is needed, linear); `type.scale` is missing (never invent it).
