## API
```
MIX.design(plan, tokens, seed) → { masterGain, limiter{threshold, knee, ratio, release}, busGains{music, sfx},
   perCueGain{CLICK, BOOP, WHOOSH, THUD, BOING, CHORD, TICK, RISER, kit{whoosh,impact,pop,click,tick,riser,ding}},
   breatherFloorGain, duck{depthDb:-6, attackMs:10, holdMs:250, releaseMs:150} }          // all numbers finite; gains > 0
MIX.apply(ctx, nodes, design, plan?) → { applied: bool, limiterInserted: bool }               // nodes = MUSIC.mix (schedule().mix); null ctx or nodes → {applied:false}, never throws
MIX.predict(design, plan) → { lufsProxy, truePeakProxy, sfxOverBedMinDb, perCue:[{name,t,overBedDb}], breatherFloorDb, seamDb }
MIX.TARGETS · MIX.BASE · MIX.VERSION
```
`apply` is the only impure code: sets `nodes.master.gain.value = masterGain`, `nodes.music.gain.value = busGains.music`, `nodes.sfx.gain.value = busGains.sfx`, `nodes.pad.gain.value = BASE.pad × breatherFloorGain` (the pad carries the breather floor: bass, pulse and motif are off there — engine L127, L303 — and the bell echo is a one-shot), inserts ONE `DynamicsCompressor` `nodes.limiter` between `nodes.comp` and `nodes.master` (idempotent: a second call reconfigures, never re-inserts; `attack` = 0), and when `plan` is given rewrites `gain` on `plan.sfx[i]` and on every `plan.events[j].type === 'sfx'` to `perCueGain[NAME]` (clamped to (0, 1]: G36 'gains', validator L398) and wraps `window.SFX_KIT.play` once (flag `__mix`) to multiply its `gain` by `perCueGain.kit[SFX_KIT.MAP[NAME]]`. Static values only: **no `setValueAtTime|RampToValueAtTime|cancelScheduledValues` anywhere in the module** (holes stay at the baseline 0; the duck automation belongs to the engine).

## Prediction law (every candidate predicts the same way, else the merger cannot compare)
dB(x) = 20·log10(x). bed = dB(master/BASE.master) + dB(music/BASE.music) + dB(breatherFloorGain)·(pad share: 1 in the breather, `BASE.padShare = 0.5` elsewhere); fx(NAME) = dB(master/BASE.master) + dB(sfx/BASE.sfx) + dB(perCueGain[NAME]/BASE.sfxGain[NAME]) + dB(kit[MAP[NAME]] || 1).
`lufsProxy = BASE.lufs + bed(elsewhere)` · `perCue[i].overBedDb = BASE.cues[i].over_bed_dB + fx(name) − bed(elsewhere)` · `breatherFloorDb = BASE.breather + bed(breather)` · `seamDb = BASE.seam + bed(elsewhere)` · `truePeakProxy = min(BASE.tp + max(bed, max fx), limiter.threshold + 1.5)` (a WebAudio compressor without lookahead overshoots ≈ 1.5 dB, so `threshold ≤ −3` is the only way to promise TP ≤ −1.5). The existing comp (−18 dB, 3:1) is ignored by predict; the probe is authoritative.
